# TTT Quản trị (app quản trị Tất Tần Tật)

App Expo (Android + iOS) cho quản trị viên: duyệt xác minh số điện thoại / CCCD, duyệt tin đăng, xem số việc cần xử lý và nhận thông báo đẩy.

- Chạy thử: `cd admin-app && npm install && npx expo start`
- Đăng nhập bằng tài khoản có vai trò MOD / ADMIN / SUPER_ADMIN (cùng API với web quản trị).
- Thông báo đẩy: thêm ứng dụng Android `com.tattantat.admin` trong Firebase, tải `google-services.json` vào thư mục này rồi build lại.
