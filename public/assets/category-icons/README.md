# Tất Tần Tật 3D Icons

## Thư mục
- `parent/`: icon danh mục cha, PNG + WebP, 256×256.
- `reference-cards/`: crop tham chiếu từng nhóm từ artwork gốc.
- `icons.json`: manifest để tích hợp web.

## Khuyến nghị
Ưu tiên WebP trên web và PNG khi cần tương thích/fallback.

> Lưu ý: artwork ban đầu là một ảnh tổng hợp do AI tạo. Các icon cha đã được tách thành asset riêng. Các icon con trong ảnh tổng hợp có chữ/đối tượng nằm rất gần nhau, nên reference cards được giữ riêng để tránh crop sai hoặc dính chữ.
