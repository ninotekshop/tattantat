# Tất Tần Tật — Web UI Starter

Bộ giao diện web responsive dựa trên ảnh UI bạn cung cấp.

## Cấu trúc
- `index.html` — trang chủ
- `styles.css` — toàn bộ CSS responsive
- `app.js` — tương tác demo
- `assets/logo-reference.png` — logo cắt từ ảnh UI tham chiếu

## Cài đặt
1. Giải nén.
2. Upload toàn bộ thư mục lên hosting/web server.
3. Trỏ domain vào thư mục chứa `index.html`.

Có thể chạy thử bằng cách mở `index.html`, nhưng để production nên dùng Nginx/Apache hoặc hosting tĩnh.

## Backend chưa có
UI hiện chưa kết nối:
- PostgreSQL
- API đăng nhập/đăng ký
- đăng tin thật
- upload ảnh
- chat realtime
- thanh toán
- quản trị quảng cáo
- tìm kiếm theo vị trí

## Khu vực quảng cáo
Sidebar trái đã có khu vực “Dành cho quảng cáo” với 4 banner minh họa. Có thể thay bằng dữ liệu từ bảng quảng cáo/backend sau này.
